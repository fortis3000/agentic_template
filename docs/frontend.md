# Frontend Architecture & Component Specification

The user interface of the Agentic Project Template is a Web-based IDE-like dashboard developed in **Svelte 5**, **TypeScript**, and **Vite**, styled with custom **Vanilla CSS** following strict glassmorphism dark-mode aesthetics.

---

## 1. Directory Structure

The frontend application resides in the root-level `frontend/` directory:

```text
frontend/
├── Dockerfile              # Docker configuration for Vite dev server container
├── index.html              # HTML entrypoint
├── package.json            # NPM dependencies and script definitions
├── tsconfig.json           # TS base configurations
├── vite.config.ts          # Vite configuration
└── src/
    ├── App.svelte          # Main layout assembly
    ├── main.ts             # Svelte application entrypoint
    ├── app.css             # Premium glassmorphic design stylesheet
    ├── svelte.config.js    # Svelte configuration
    └── lib/                # Reusable dashboard UI components and logic
        ├── Sidebar.svelte  # Session & Config Selector
        ├── ChatPanel.svelte# Markdown conversation view
        ├── TracePanel.svelte# Telemetry & Tool-call execution logger
        ├── FileBrowser.svelte# Workspace output explorer
        └── agent.svelte.ts # Svelte 5 reactive controller and SSE stream handler
```

---

## 2. Reusable UI Components

The dashboard is composed of four main custom Svelte components, each designed for high maintainability, reuse, and strict typing compliance:

### 1. `Sidebar`
- **Location**: `src/lib/Sidebar.svelte`
- **Purpose**: Provides session history management and dynamic agent behavior configuration.
- **Key Features**:
  - Dynamically lists agent config files loaded from the backend `/api/configs` endpoint.
  - Displays recent chat sessions sorted by last updated timestamp.
  - Triggers the initialization of a fresh workspace chat session.

### 2. `ChatPanel`
- **Location**: `src/lib/ChatPanel.svelte`
- **Purpose**: Presents the conversational workspace interface between the user and the agent.
- **Key Features**:
  - Streams token-by-token agent text generation in real-time.
  - Safe HTML rendering of agent Markdown outputs and monospaced code blocks using the `marked` library.
  - Integrates an execution cancellation "Stop" button that triggers backend thread interruption.
  - Supports text file attachments (PDF, TXT, Markdown, HTML) with client-side validation of file type, size, and count limits.
  - Renders attached file metadata as compact chips in message bubbles with file icon, name, and size.

### 3. `TracePanel`
- **Location**: `src/lib/TracePanel.svelte`
- **Purpose**: Displays tool executions and step-by-step reasoning logs dynamically.
- **Key Features**:
  - Shows real-time tool state updates (`running`, `completed`, `error`) matching OpenTelemetry trace stages.
  - Expandable panels showing exact tool JSON inputs (args) and outputs or stack trace details in case of errors.
  - Rotating spinner icons for running processes, checkmarks for success, and warn symbols for errors.

### 4. `FileBrowser`
- **Location**: `src/lib/FileBrowser.svelte`
- **Purpose**: Displays output files generated by the agents in the workspace `data/` directory.
- **Key Features**:
  - Scans and lists files dynamically using file extension icons.
  - Computes and displays human-readable file sizes.
  - Includes a refresh trigger to sync local file state.

## 3. Communication & State Management Controller

### `AgentController` class (`src/lib/agent.svelte.ts`)
The core UI application logic and API bindings are encapsulated in the Svelte 5 reactive class `AgentController`. It exposes:
- **Reactive State (Runes)**: Uses `$state` runes for `messages`, `toolCalls`, `isGenerating`, `configs`, `sessions`, and `files` to trigger highly targeted, performant DOM updates without virtual DOM overhead.
- **SSE Stream Reader**: Opens a readable fetch stream on `GET /api/agent/stream/{session_id}`. Reads the raw text buffer, splits payloads by `\n\n` boundaries, parses event types (`token`, `tool_start`, `tool_complete`, `done`, `cancelled`, `info`), and propagates incremental updates directly to Svelte reactive state variables.
- **REST Operations**: Handles standard HTTP triggers for fetching list data (`/api/configs`, `/api/sessions`, `/api/files`, `/api/files/uploads/{session_id}`), retrieving history by session, starting chat execution (with optional image and file attachments), and sending stop signals.

## 4. Visual Design System (`src/app.css`)

The visual style implements a **glassmorphic dark-mode theme** built entirely with Vanilla CSS variables and transition tokens:
- **Palette**: Tailored dark colors (primary background `#0a0b0e`, secondary panels `#13151a`) to replace browser defaults.
- **Glassmorphic Panels**: Translucent card backdrops (`backdrop-filter: blur(10px)`) coupled with soft borders (`rgba(255,255,255,0.08)`) and glowing indicators.
- **Typography**: Responsive fonts using the system sans-serif scale, with `Outfit` / `Fira Code` monospaced styling for terminal traces and config files.
- **Transitions**: Native animations for hover states, button expansions, and spinning execution indicators (`@keyframes spin`).
